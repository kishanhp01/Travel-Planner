# Travel Planner Pro

A polished travel-planning web app with animated UI, travel dashboard features, and a clean multi-page experience.

## What’s included
- Landing page with modern visuals and animations
- Login and sign-up pages
- Dashboard with trip summary cards
- Trip creation page with budget, packing, weather, and route tools
- Trip history, profile, and settings pages
- Dark mode support

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript

## Files overview
- index.html: landing page
- login.html / signup.html: authentication UI
- dashboard.html: main dashboard
- create-trip.html: trip planner form
- history.html: trip history page
- profile.html: user preferences page
- settings.html: settings page
- css/: styling files
- js/: frontend logic and interactions
- assets/images/: visual assets
