# 🗺️ Travel Planner

A modern and responsive web application that helps users organize trips, manage travel budgets, track packing lists, check weather forecasts, and plan journeys with ease.

## ✨ Features

- 🔐 User Login
- 🧳 Create and Manage Trips
- 💰 Budget Planner
- 🎒 Packing Checklist
- 🌦️ Live Weather Information
- 🗺️ Google Maps Integration
- 📜 Trip History
- 📱 Fully Responsive Design

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/kishanhp01/Travel-Planner.git
```

Navigate to the project folder

```bash
cd Travel-Planner
```

Open `index.html` in your browser.

Or use VS Code Live Server.
